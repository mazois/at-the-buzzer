# At The Buzzer

An NBA schedule and scores tracker built with React, TypeScript, and Vite.

## What it does

Browse NBA games by team and month — see scores for completed games and upcoming matchups with broadcast info.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Zustand (state)
- TanStack Query
- shadcn/ui

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
